# iph
[IPH] Image Particle Hallucination

Create neural hallucinations by encoding images as particle sets into the manifold of a linear network.

Set the image path in the CONFIG.py file. Then run "python Main.py --action train" to train a network model. The "data/out/frames/" folder will contain the images which show the progress of learning.

This repo is primarily useful as an educational tool to help students understand neural interpolation.
